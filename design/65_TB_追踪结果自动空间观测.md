# TB 阶段：追踪结果自动生成空间观测（V0.1）

## 目标

B8-S 的投影链路此前只服务于 8 个固定测试地物点。本阶段把它接回真实追踪结果：
目标框 → 地面接触点 → 参数射线投影 → 实验估计地面点 → 实验图层，全程与正式 L2 隔离。

## 链路

```
track samples [{t, box[x1,y1,x2,y2]}]
  → m6_ground_contact.from_box  → contact_pixel + contact_quality
  → m6_camera_ray_projection.project → ground_point(EPSG:4326) + uncertainty_radius_m
  → 观测序列（layer=experimental_estimate, persisted=false）
```

## 隔离与降级规则

- 不写 `target_spatial_observations`，不产生正式 L2，不参与身份判断；
- 每点必须带 `spatial_level` 与 `degrade_reason`（如 `contact_at_frame_bottom`、`hfov_deg_missing`）；
- 接触点质量 `cut_off` / `far_field` 仍照常投影，但必须出现在观测的 `contact_quality` 里；
- 汇总给出 `projected / degraded / reliable_ratio`，避免只看成功率。

## 实测结果（2026-11-05）

- 素材：试点录像 00:00:05 起 80 s、2 fps、960×540（框按 0.5 折算回 1920×1080）；
- 方法：MOG2 前景 + IoU/质心跨帧关联，取最长连续轨迹；
- 结果：33 帧连续轨迹，`projected=33`、`degraded=0`、`reliable_contact=28`；
- 首帧接地点贴画面底边（`cut_off`，y=1080），末帧为 `estimated`（y=426）——质量标记在真实数据上有区分度；
- 每个点携带 `quality=experimental_estimate`、`degrade_reason`（成功时为 null）、
  `evidence={clip,fps,method,sample_scale}`、`t`、`contact_quality`、`uncertainty_radius_m`；
- 接口 `GET /api/v1/track-spatial/sample`、`POST /api/v1/track-spatial` 均 `persisted=false`；
- 隔离测试：调用前后 `target_spatial_observations` 行数不变。
