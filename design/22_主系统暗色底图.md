# 主系统地图暗色底图（2026-10-29）

> 目标：主系统（`TrajNexa_main`）的地图底图改成暗色，观感与 `TrajNexa_Map` 的暗色模式一致。
> 结论：**照抄 TrajNexa_Map 的做法——在瓦片层加 `brightness(0.7) contrast(1.2)`，不做反相、不换瓦片服务。**

## 1. TrajNexa_Map 是怎么做的

源码在 `G:\MyProject\公益项目\TrajNexa\TrajNexa_Map\front-end`，三处：

1. `src/js/map.js:87-110`：每套底图（OSM / HOT / Esri 影像）建 `L.tileLayer(...)` 时都带
   `className: "dark-map-tiles"`。
2. `src/css/main.css:38-41`：

   ```css
   .dark-map-tiles {
     filter: var(--dark-map-filter, none);
     transition: filter 0.3s ease;
   }
   ```

3. `src/js/map.js:261-269`：监听自己的 `themeChanged` 事件（页头月亮按钮），按主题写变量：

   ```js
   root.style.setProperty("--dark-map-filter", theme === "dark" ? "brightness(0.7) contrast(1.2)" : "none");
   ```

也就是说：**Map 的"暗色"= 瓦片整体压暗 30% + 提对比 20%，颜色关系完全不变**（陆地米白 → 灰、建筑米色 → 灰米、
主干道橙 → 暗橙、注记仍是深灰、路网仍是白线）。没有反相，也没有第二套瓦片。

## 2. 主系统怎么做的

一处滤镜、两个类挂点（`src/styles/map.css`）：

```css
.is-dark-base .leaflet-tile-pane {
  filter: brightness(0.7) contrast(1.2);
  transition: filter 0.25s ease;
}
```

| 位置 | 什么时候挂 `.is-dark-base` |
| --- | --- |
| `WorkspaceMap.vue` 的 `.map-canvas` | 底图 = 「地图」时（切「卫星」就摘掉） |
| `LiveGisMap.vue` 的 `.gis-live` | 勾选「在线暗色瓦片」时 |

滤镜只作用在 `.leaflet-tile-pane`：标记在 markerPane、视域矢量在 overlayPane、弹窗在 popupPane，
辨识 `#ff3131` / 识别 `#ffbf00` / 观察 `#00b300` 三色不受影响。

与 TrajNexa_Map 的唯一差异：**卫星影像不压暗**（Map 把三套底图都挂了 `dark-map-tiles`）。
影像要当人工判读依据，所以主系统的「卫星」保持原色；如果要求完全一致，把 `.is-dark-base` 也挂到卫星模式即可（一行）。

## 3. 为什么不用其它造型

| 方案 | 结论 |
| --- | --- |
| `filter: invert(1) hue-rotate(180deg)`（网上常见的"OSM 暗色"） | 颜色够"夜"，但 OSM 路面是白色，反相后**路面比底色更暗**，路网层级整个翻过去，城市尺度糊成一片。弃用。 |
| CARTO Dark Matter 瓦片 | 现在要 API Key，无 Key 取到的瓦片整片盖 `API KEY REQUIRED` 水印（实测 18/18 都加载成功但路名全无）。弃用。 |
| Esri Dark Gray Canvas | 免 Key，但官方只承诺全球 0–10 级，11 级起仅覆盖北美/欧洲/印度等地区，中国境内没有；本项目固定在 16–19 级看。弃用。 |
| 自绘矢量底图（MapLibre + 自制 style） | 效果最好，但要一套瓦片服务和样式工程，远超这次改动的范围。 |

## 4. 配套的配色调整

| 元素 | 处理 |
| --- | --- |
| 容器底色 `--map-bg` | `#b1afab`（压暗后的 OSM 陆地色），瓦片加载中不闪白/闪黑 |
| 镜头名 / 轨迹 / 区域锚点标签 | 仍是深字 + 白描边（这套设计本来就按浅底写的，压暗后的灰底上照样可读） |
| 悬浮提示 `.map-tip` | 白底深字，边框加深到 `#b9c2cc` |
| 底图边缘 | 一道很淡的内阴影（`inset 0 0 26px rgba(23,32,42,.14)`），瓦片不硬贴在工具条下面 |
| 真实 GIS 的 Leaflet 控件 | 缩放 / 图层控件改深色（该视图本来就是深色画布 + 深色状态栏） |

## 7. 待确认

- OSM 瓦片（`tile.openstreetmap.org`）是给 OSM 地图用的公开服务，不承诺 SLA、不允许批量抓取；demo 可用，
  正式交付建议换自建或采购的瓦片服务（`basemapTiles.ts` 一个常量）。卫星影像同属 Esri 公开服务，条款同上。
- 与 Map 的差异（卫星不压暗）是有意的；要完全一致就去掉 WorkspaceMap 里 `is-dark-base` 的 `basemap === 'map'` 条件。
