# 35｜Demo 模式：移除权限/授权门槛

TrajNexa 当前定位为本地 Demo：不设计登录、RBAC、案件访问授权，也不要求用户逐次勾选“已授权”。

## M4d 本轮变更
- `m4d_experiment.ExperimentSource` 删除 `authorization_checked`，继续校验案件/素材标识、帧偏移和图像 SHA-256。
- `m4d_case_guard.resolve_case_clip` 不再接收 `can_read_case` 回调，只复用 M4c 的案件-录像关联、路径和文件变更检查。
- 对应离线测试同步修改；不添加 HTTP 接口，不改变已有案件数据。
- 模型输出仍仅为未经确认的属性候选，不能自动确认跨镜头身份。

## 非权限类校验仍需保留
- 录像归属当前案件，避免串案；
- 路径不能越界，录像扫描后不能被悄悄替换；
- 模型/图像输入边界、异常处理与来源追溯；
- 资源占用和推理并发限制。

## 待统一清理
既有 M4a、M4b、M4c HTTP API 仍存在 `authorized` 请求字段和相关前端勾选。本次先清理实验分支 M4d 的权限依赖，后续单独修改现有接口与 UI，并更新回归测试，避免无意破坏已有 Demo 功能。

## 部署边界
无认证的 Demo 接口只适合受控本地环境，不应直接暴露公网。真实监控数据和第三方模型服务的数据发送规则仍需按实际部署环境处理。
