# M1b｜真实监控时间角标识别失败：定向修复

日期：2026-10-26。用户报告：PaddleOCR 3.7.0（PaddlePaddle 3.2.0）已运行，底部设备编码角标可读，但顶部时间状态为 unreadable。**还不能确认是 OCR 文字检测失败还是时间解析失败。**

## 修复点

- 仅在原始上下边缘 OCR 无法解析合法完整日期时间时，针对右上 50% 宽、顶部 13% 高区域额外执行 OCR。
- 依次使用局部两倍放大、CLAHE、亮色文字阈值预处理；检测到完整合法日期时间则不再重复调用 OCR。
- 日期文本可兼容部分全角符号及分隔符，但不补猜关键数字、不从文件名偷偷填补 OCR 时间。
- 报告新增 time.ocr_time_diagnostics：顶部原始识别文字、置信度、区域、预处理方式及是否执行定向重试；在前端 unreadable 时显示。
- 不改变摄像头绑定规则、TrajNexa_Map 或证据真实性判断；高文本置信度不代表真实拍摄时间已校验。

## 本机复测

先更新代码，再重建 OCR Worker，重新点击同一张截图的「开始媒体预检」（旧报告不会自动更新）。

    git pull
    docker compose -f compose.yaml -f compose.ocr.yaml up --build -d

若时间仍 unreadable，请查看报告中 ocr_time_diagnostics.top_raw_texts 的原文，以区分「未检测」和「文本格式不完整」。注意：镜像体积约 2.18 GB 为用户反馈，本补丁未优化镜像大小。

## 已做与未做验证

本地注入式 OCR 回归覆盖格式解析、ROI 增强路径、结构化设备角标保持待绑定、文件名提示隔离。**不能凭这些单元测试保证 PaddleOCR 在实际上传的图像上读出时间**；待用户真实 Worker 复测后验收。
