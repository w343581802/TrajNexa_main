# 轨迹点证据视频播放修复

> 依据：用户 2026-11-06 反馈（m04761）：“如图，播放是无法点击的”。
> 范围：只改前端证据面板交互，不改代理视频接口、不写空间观测、不改变身份/空间结论。

## 一、问题与根因

- 证据弹窗原先使用原生 `<video controls preload="metadata">`，下方显示黑屏 0:00。
- 实测原生 controls 在深色面板里点击底栏 (715,488) 后，`currentTime=0, paused=true`：该点落在进度条最左端，点击没有稳定命中播放键。
- 程序化 `video.play()` 在无用户手势时被浏览器拒绝（`NotAllowedError`），因此不能靠自动播放兜底。
- 面板增高后总高 621px，超过地图可视高度 597px，面板 header 被顶到 `y=-24`，进一步降低可操作性。

## 二、实现

文件：`frontend/src/components/WorkspaceMap.vue`

- 去掉原生 `controls`，改为显式播放层：
  - 视频中央 `.evidence-play-overlay`：播放三角 + “播放片段”/“代理片段加载中…”。
  - 视频下方 `.evidence-transport`：播放/暂停按钮、进度条、当前/总时长。
  - 视频本身也可点击播放/暂停，`:poster` 使用同点关键帧，避免 0:00 纯黑。
- 状态：`evidencePlaying / evidenceDuration / evidenceCurrent / evidenceLoading / evidenceError`。
- `seekEvidenceVideo()` 在 `loadedmetadata` 后按 `offset - start - 0.5` 定位并夹到 `duration - 0.1`。
- `@waiting/@playing/@error` 显示加载与解码错误；解码失败时提示 `MEDIA_ERR_SRC_NOT_SUPPORTED`，不伪装成可播放。
- 面板改为纵向 flex，`max-height: calc(100% - 24px)`；卡片 `min-height:0; overflow-y:auto`，保证 header 始终可见。

## 三、验证

- CDP 可信点击 `.evidence-play-overlay` 后：`t=1.0898, paused=false, overlay=false`，视频实际开始播放；再点 transport 可暂停。
- 面板实测：card 高 533，`scrollHeight=602`、`clientHeight=531`，header 可见；内容超出时在卡片内滚动。
- `vue-tsc --noEmit` 通过。
- 截图：`assets/73_evidence_video_controls.png`。

## 四、边界

- 代理片段为 H.264 重编码，非原片；PTS 未与 OSD 独立核验。
- 播放可用不等于身份确认，也不等于空间精度达标；身份与空间质量仍分别标注。
- 未新增任何正式 L2 或空间观测写入。
