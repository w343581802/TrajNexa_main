## 2. T0：冻结基线、建立独立人工真值

### 2.1 素材与目标

主实验集用**菜市入口**（已有 0.5 fps 图库），补充**松山巷**做运动目标对照。

| 编号 | 目标 | 帧数目标 | 用途 |
| --- | --- | --- | --- |
| GT-1 | 摊主 A（坐姿，125 px） | ≥20 帧 | 静态、长期在场 |
| GT-2 | 摊主 B（坐姿，131 px） | ≥20 帧 | 静态、第二名干扰 |
| GT-3 | 行走顾客（72 px，192–214 s） | 12 帧 | 移动、遮挡、被截断 |
| GT-4 | 相似外观干扰者（同时段白衣者） | ≥5 帧 | 难负例 |
| GT-5 | 一条遮挡/交错轨迹（菜市或松山巷） | ≥10 帧 | 断轨与恢复 |

### 2.2 标注方法（避免循环验证）

1. 用现有 IoU 跟踪**只做候选轨迹挑选**，为每条候选导出按时间排列的 contact sheet。
2. 人工逐帧核对：同一人 → 记录 bbox；出现换人 → 在该帧截断为新段，并标注 `id_switch_at`。
3. 真值文件独立于算法输出，不从评测结果反推。

产出：`backend/scripts/fixtures/m6_track_ground_truth.json`

```json
{
  "schema_version": "m6-track-gt-v1",
  "video_id": "market_camera_01",
  "source": {"path": "...", "sha256": "...", "sample_interval_seconds": 0.5},
  "tracks": [{
    "gt_id": "person_001",
    "category": "person",
    "frames": [{"frame_id": "t_0100", "bbox": [610, 290, 650, 381],
                "visibility": "visible", "quality": "usable"}]
  }]
}
```

### 2.3 E0 基线（必须保留）

用同一份图库、同一批人工真值，跑**单帧、无轨迹**的现状算法，输出：目标本人分数、该帧最高分、Top-1/Top-5、缺席误收。这份数字是 T2 的唯一对照物。

### 2.4 T0.1 进展（2026-11-02）

已落盘：`backend/scripts/fixtures/m6_track_ground_truth.json`（`m6-track-gt-v1`）。

| gt_id | 内容 | 帧数 | 时间 |
| --- | --- | --- | --- |
| `person_001` | 菜市摊主（深色短袖，蹲在摊前） | 24 | 1710–1756 s |
| `person_003` | 行走顾客（粉紫上衣，提橙色袋子） | 12 | 192–214 s |
| `person_004` | 相似外观干扰者（浅色上衣 + 肩包） | 11 | 220–240 s |

**核验中直接抓到两个问题：**

1. **贪心 IoU 在 216 s 换人。** 原目标离开画面后，相邻位置另一人接管了同一条轨迹。
   这解释了我此前"行走轨迹 12 帧"的来源——超过 214 s 的部分已经不是她。
   该案例已写进真值的 `id_switch_evidence`，作为 T1 的验收用例（E1/E2 必须不复现）。
2. **菜市机位的"静态摊主"其实是误检物体。** 逐帧看发现那两个框是停放电动车与遮阳棚，
   已同步在 [43 号文档 §13.3](43_M6目标特征库_ReID_属性时空匹配与动态更新验证方案.md) 加勘误：
   这两个 Top-1/Top-5 不能当人员结论，人员结论只保留行走顾客。

**待补**：真实静态摊主（GT-2）与遮挡/交错轨迹（GT-5）；以及该机位 person 检测的静态误检率。

## 3. T1：单镜头轨迹关联（`app/m6_track.py`）

### 3.1 数据结构

`DetectionObservation`（frame_id / timestamp / bbox / conf / embedding / quality）→ `Tracklet`（track_id / observations / state / last_seen / missing_frames / fragments / decisions）。

### 3.2 关联与状态

- 关联分 `S = α·S_IoU + β·S_距离 + γ·S_外观`，**α/β/γ 不预设为产品值**，由 E1–E3 消融决定。
- 中心距离按画面尺度归一化（`dist / sqrt(W·H)`），不跨分辨率复用像素阈值。
- 缺口同时受 `max_missing_frames` 与 `max_missing_seconds` 约束（0.25 s 采样下 3 帧≈0.75 s；2 s 采样下 3 帧≈6 s，两者不可混用）。
- 状态：`tentative → active → lost → ended`；`lost` 只表示"暂时没看到"，不等于离场。
- 一对一：先做确定性贪心基线，再与匈牙利匹配对照；歧义时保留 `ambiguous` 而不是硬拼。

### 3.3 碎片归属（本阶段的核心验收点）

按 4.5 的顺序判断：小框中心是否落在大框内/近邻 → 面积与包含比例 → 与轨迹预测位置是否一致 → 前后帧是否连续 → 是否存在第二个同样合理的解释。**有歧义就保留待核查关系。**

处理规则：完整人体框为主观测、头肩框为辅助观测；Top-K 按轨迹去重；碎片向量不得直接污染轨迹参考。

### 3.4 测试清单（`tests/test_m6_track.py`）

确定性用例，不依赖真实录像：两人平行走过的正常关联、一人被短暂遮挡后重接、两人交错导致 ID Switch 的防护、头肩碎片归属、长期离场后不无限重接、检测异常必须上抛（不得表现为"没有目标"）。

### T1 完成条件（DoD）

- 5 条真值轨迹能形成合理 tracklet，无严重错误合并。
- 碎片案例（29×42 与 38×87）归属正确，不再挤占第二个候选名额。
- 断轨数下降，且 ID Switch / False Merge 不恶化。
- 每个合并与拒绝决定都有可追溯原因。

## 4. T2：多帧聚合与轨迹级检索

### 4.1 聚合方案（四选一，必须对照）

单帧最大 / 全轨迹平均 / Top-k 均值（k=3 起步）/ 质量筛选 + 时间分散。

轨迹分同时输出：`track_similarity`、`best_frame_similarity`、`median_similarity`、`valid_observations`、`missing_duration`、`fragment_count`、`motion_consistency`、`decision`。

**不把各维度加权成一个"身份概率"。**

### 4.2 消融矩阵 E0–E6

| 实验 | 关联 | 缺口 | 碎片 | 聚合 |
| --- | --- | --- | --- | --- |
| E0 | 无（现状单帧） | 无 | IoU 0.5 去重 | 无 |
| E1 | IoU | 无 | 同帧去重 | 无 |
| E2 | IoU + 距离 | 有 | 同帧去重 | 无 |
| E3 | IoU + 距离 + ReID | 有 | 同帧去重 | 无 |
| E4 | 同 E3 | 有 | 新碎片归属 | 无 |
| E5 | 同 E4 | 有 | 新碎片归属 | Top-k |
| E6 | 同 E4 | 有 | 新碎片归属 | 质量 + 时间分散 |

### 4.3 指标与工件

指标：Track Recall（分母=人工可见帧）、Track Precision、ID Switch、Fragmentation、Occlusion Recovery（仅 lost 占位不算成功）、Track Top-1/Top-5、False Merge、False Accept、处理耗时。

工件：`tracks.json`、`track_metrics.json`、`errors.json`、`track_contact_sheet.jpg`、`run_manifest.json`。

**口径红线**：`target_similarity`（目标本人）与 `best_similarity`（全帧最高）不得混用；困难帧不得移出分母。

### T2 完成条件（DoD）

- E0–E6 在真值上报出完整表格，每个数字有脚本可复现。
- 至少证明：低分遮挡帧不再导致轨迹失联，且 ID Switch / False Merge / False Accept 没变差。
- 一页正负结论 + 失败案例图。

## 6. 验收门

**G1（T1→T2）**：5 条真值轨迹无严重错误合并；碎片归属正确；断轨改善；遮挡恢复有真实重观测证据；错误列表可解释。*仅轨迹变长但换人增加 = No-Go。*

**G2（T2→T3）**：与 E0 相比有可复现增益；低分遮挡帧处理合理；False Accept / ID Switch 不恶化。*不通过则保留单帧方案，不进 UI。*

## 7. 风险与回退

- **抽帧过稀**：追踪采样与特征采样分离，保留 0.25–4 s 对照。
- **交错换人**：一对一 + 外观一致性 + 歧义保留。
- **碎片占位**：带前后文的碎片归属，绝不直接降 IoU 阈值。
- **误合并**：宁可拆轨，不用轨迹长度掩盖身份污染。
- **回退**：新方案使 ID Switch / False Merge / False Accept 明显恶化 → 停止接 UI，保留 P1-A-5 单帧实验作为可用基线。
