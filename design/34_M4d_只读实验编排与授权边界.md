# 34｜M4d 只读实验编排与授权边界 V0.1

状态：实验分支已提交；CI 结果以 GitHub Actions 为准。**无 HTTP 路由、无模型权重、无真实图像测试。**

## 新增能力
- `backend/app/m4d_experiment.py`：组合 `review_jpeg` 和 `parse_attribute_candidates`，保留 case_id、media_id、frame_offset_ms、图像 SHA-256。
- 调用前验证来源字段、图像哈希与 `authorization_checked` 标记；模型输出永远需要人工审核。
- `backend/tests/test_m4d_experiment.py`：离线验证成功路径、来源不一致、未授权、无效输出。
- 不改变 M4b、M4c、录像源、轨迹、地图数据、数据库或现有接口。

## 安全边界
- `authorization_checked` 是**可信服务层声明**，不是 RBAC 实现，也不能由浏览器、HTTP 请求体或未认证客户端直接设置。
- 当前没有对案件/媒体关系进行数据库核验；不得将此实验函数直接暴露成公开 API。
- 实际运行前必须实现可信案件授权、素材归属验证、模型数据驻留策略、审计记录、脱敏与费用/超时控制。
- 模型输出只是未经确认的可见属性候选；不进行身份推断或自动跨镜头关联。
