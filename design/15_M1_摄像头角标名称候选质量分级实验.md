# CCTV 摄像头名称 OCR 候选质量分级（独立实验 V0.2）

本版延续 PP-OCRv6，**仅更新** `scripts/benchmark_camera_name_roi.py` 的候选分类，不修改正式 MediaInspector、数据库、已有人工绑定及主 UI。

来自六张用户实拍 OCR 的诊断：
- `26382f40`：`98号` / `中仁98号` / `中1路8号` → `ocr_variants_require_review`，保留数值字符不一致警告。
- `f661a233`：`问北` / `向北` / 缺后缀 → `ocr_variants_require_review`，不把问北自动改写为向北。
- `d74280e6`：`DX电仁路孔L明园E40东庭向北工` → `low_quality_name_requires_review`，**不产生可靠名称候选**。
- `0285993c`：紧凑 ROI 左侧缺 `3` → `candidate_with_roi_warning`，保留 `roi_left_edge_clipping` 和原始文本。
- 真正不同的 `E40/E41`、`向北/向南` 不会被文本相似度合并。
- 车牌、招牌等普通场景文字继续不成为摄像头名称。

所有输出保持 `camera_uuid:null` 与 `no_auto_binding:true`；相似度分组不是设备身份识别，**格式完整也不能证明中文字正确**。本版本仍使用固定前缀/地名锚点/常见后缀启发式，不能穷举所有监控 OSD；其他设备名称必须通过已校验目录别名或人工核对。

本地：`cd backend && python -m pytest -q tests/test_camera_name_quality.py tests/test_camera_name_roi.py`。新增 6 项独立质量测试已通过；实机 PP-OCRv6 六张图片的完整复跑尚需在用户 Worker 上验证。

docker compose exec -T worker python scripts/benchmark_camera_name_roi.py /data/storage/validation/name_sample.png --output /data/storage/validation/name_roi_v02.json
