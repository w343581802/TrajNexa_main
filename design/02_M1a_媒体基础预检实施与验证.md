# M1a｜真实媒体基础预检实施与验证（TrajNexa 主系统）

> 实施状态：本地 2026-10-25 已通过 9 项 Python 自动化测试；Docker 容器、浏览器与异构 GPU 环境未做实际启动验证。

## M1a 已实现

- 图片：通过 OpenCV 解码，读取真实像素尺寸，记录亮度中位数与 Laplacian 方差（**纹理/模糊候选指标，非证据级画质结论**）。损坏文件返回 `decode_status=failed`。
- 视频：FFprobe 返回容器格式、视频流、持续时间及技术参数；探测失败返回可解释状态。`decode_status=metadata_only` **不代表全片解码正常**。
- 保持原件 SHA-256 校验，报告包含原始媒体 ID、来源哈希与明确的模块版本。
- 时间 OCR、设备名称 OCR、地理方位/视角验证一律 `not_checked`，不伪造任何时间、摄像头或朝向。
- 旧 M0 的测试用例仍被保留，增加实图、损坏图和可合成有效测试视频的测试用例。

## 开源组件

- FFmpeg/FFprobe：视频元数据探测（Docker 中安装 ffmpeg）。
- OpenCV（opencv-python-headless）：静态图像解码与粗略画质指标。
- FastAPI + PostgreSQL：沿用 M0 媒体与任务记录，主流程不改。
