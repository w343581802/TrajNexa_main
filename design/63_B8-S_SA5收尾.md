# B8-S V1.2 阶段收尾：SA2 负结论、SA3 候选隔离、SA5 实验图层接口

## SA2（CV_ONLY / QWEN_CV）

| 路径 | 结果 | 证据 |
|---|---|---|
| 结构线消失点 | conflict | VP (172,5.5)，167 内点，距台账地平线 181.9 px |
| 运动方向 | unstable | 80 s 内仅 4 条纵深轨迹，两两交点散布全画面 |
| QWEN_CV | divergent 且更慢 | VP (1614,396)，85 内点，24.5 s/帧 |

结论：该镜头在当前素材下无法由视觉独立验证 25° 俯角与 64° FOV；
自动标定只能停在 experimental_estimate，不改台账、不启用 Qwen 几何路径。

## SA3（Map 侧）

- 迁移 0035：auto_candidate 状态 + source/method/evidence/validation_status；
- 只读候选接口 GET /api/v1/ground-calibrations/candidates/，仅返回 auto_candidate；
- 主系统读取仍只认 approved，自动候选无法进入正式 L2。

## SA5（主系统）

- POST /api/v1/experimental-projection：参数射线投影，返回 experimental_estimate，
  固定 persisted=false，不写 target_spatial_observations；缺 FOV 等参数时逐点降级为 L1 + degrade_reason。

## 回归测试修正

原测试用 `app.routes` 列表断言存在该路径，实测不可靠：同一进程里 `len(app.routes)==36`、查不到
`/api/v1/experimental-projection`，但 `TestClient(app).post(...)` 返回 200，说明该列表不能当作
实际路由表使用。改为发送真实 POST，断言 200 + `layer=experimental_estimate` + `persisted=false` + `L2-candidate`。
