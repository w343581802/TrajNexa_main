# 23_底部任务控制与侧栏资源页

> 2026-11 调整：底部只保留「任务控制」，不再有分区标签；
> 「录像资源」「历史记录」移到左侧主菜单，独立成页；「候选结果」整个删除。

## 1. 新的信息架构

```
左侧菜单                         底部
├─ 研判工作台（地图 + 时间线）      └─ 任务控制（唯一分区）
├─ 录像资源（独立页）
├─ 历史记录（独立页）
├─ 小模型管理
├─ 大模型管理
└─ 模型测试
```

| 入口 | 位置 | 内容 |
| --- | --- | --- |
| 任务控制 | 底部固定面板 | 轮次摘要、活动文字、继续/暂停/终止/追踪任务、要素与作业统计；右栏为目标特征 |
| 目标特征 | 底部任务控制右栏 | 目标主图、查看详情/编辑特征、特征格、参考要素入口、添加要素 |
| 观测时间线 | 右侧整列 | 从顶栏下沿到底部，占满右侧；左边缘可拖宽 |
| 录像资源 | 左侧菜单页 | 添加视频 / 挂载目录 / 开启分析 / 自动分析 / 刷新；左目录列表，右视频文件表 |
| 历史记录 | 左侧菜单页 | 轮次归档空态（归档接口未接入前保持真实空态） |
| 候选结果 | 已删除 | 不再有底部标签、统计面板和候选条目列表 |

## 2. 任务控制（底部）

- 底部 `BottomDock.vue` 删除 `dock-tabs` 导航，只渲染任务控制左右两栏；折叠条仍显示「任务控制」。
- 左栏：`R2` 轮次、起始要素与方向、时间范围；`activityView` 文字说明（不用百分比）；
  继续分析 / 暂停 / 终止 / 追踪任务；要素 / 作业 / 分析中 / 待审核；录像索引与「添加」。
- 右栏：`TargetFeatureBar`（`embedded` 模式），替换原「正在分析」卡片；不再有缩略图/缩略视频开关、待审核卡片和空态。
- 目标特征栏嵌入后隐藏折叠按钮与参考要素缩略图，高度跟随底部面板；特征格横向滚动，不挤压左栏。

## 2.1 右侧时间线与地图

- `App.vue` 工作区改为两列：左列 = 地图 + 底部面板，右列 = `ObservationTimeline`。
- 时间线 `position: absolute` 左边缘拖拽条：默认 460px，最小 380px，最大 720px 或视口 55%；
  拖动实时写 `--rail-w`，松手记 `localStorage`，双击恢复默认。
- 地图不再被目标特征栏挤占，直接占满左列上半区；底部面板只位于地图下方。
- 时间线字号与任务控制同档：标题 14px、正文 12.5px、筛选 12.5px；空态文案 12.5px。

## 3. 录像资源（左侧菜单页）

`RecordingResources.vue` 复用原底部面板的数据与操作，改成整页布局：

- 顶部标题 + 操作：添加视频、挂载目录、开启分析、自动分析、刷新。
- 左侧：案件、文件/未匹配统计；目录卡片（状态、文件/匹配数、自动开关、重新匹配、扫描、移除）。
- 右侧：视频文件信息表（开始时间与来源、摄像头、文件名、时长、匹配状态、审核）。
- 打开页面即每 4 秒轮询扫描进度，离开页面停止；审核弹窗保存后仍按台账重新匹配并刷新。
- 只读扫描，不改动、不搬移录像文件。

## 4. 历史记录（左侧菜单页）

`HistoryPage.vue`：标题、说明与空态卡片。归档接口未接入前不伪造轮次数据。

## 5. 候选结果删除范围

- 删除底部「候选结果」标签与整个统计/候选条目面板。
- 删除 `store/workbench.ts` 的 `analyzedView` 计算与相关样式。
- 提示语不再说「进入候选结果」，改为「记为已核实观测 / 不计入研判结果」。
