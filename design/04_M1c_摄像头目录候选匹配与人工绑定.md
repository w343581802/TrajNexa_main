# M1c｜摄像头目录候选与人工确认（TrajNexa 主系统 Demo）

仅使用只读本地 GIS 快照，不写 TrajNexa_Map。真实 Map 发布 API / camera_uuid 仍待对接与验证。

本地放置 examples/camera_catalog.demo.json 到 storage/camera_catalog.json；示例设备完全虚构。
文件包含 schema_version=1.0、spatial_revision、cameras[{camera_uuid,display_name,aliases,active}]。

处理规则：OCR 角标只生成别名候选；NFKC/大小写/空白规范化后做精确匹配；重名 ambiguous_alias，无匹配 no_exact_match，OCR 冲突 conflicting_overlay_names。自动报告 camera_uuid 始终为 null。
报告保存目录版本、SHA-256 和候选理由。人工在本地确认、改绑、撤销均向 camera_binding_decisions 追加一条记录，不修改原始报告。

API：GET /api/v1/cameras/catalog；GET /api/v1/inspections/{id}/camera-bindings；POST /api/v1/inspections/{id}/camera-bindings。
POST JSON 示例：{"decision":"confirm","camera_uuid":"11111111-1111-4111-8111-111111111111","note":"人工核实录像通道和设备清单"}。
撤销：{"decision":"revoke","camera_uuid":null,"note":"再次复核发现来源不明确"}。

升级数据库：在项目 backend 执行 alembic upgrade head，或按现有 Docker Compose 迁移服务启动；不要删除数据库卷。

验收：离线测试目录有效性、同名冲突、禁用设备、人工确认/更正/撤销、报告不变。
未验收：真实 PaddleOCR 精度、TrajNexa_Map 实际设备快照、Docker Desktop、浏览器构建、地图视角验证（M1d）。
Demo 无用户鉴权，须仅用于本地授权测试数据，禁止直接公网部署。
